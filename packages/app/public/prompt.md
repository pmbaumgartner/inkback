# Roughdraft workflow

The reusable workflow is distributed as an Agent Skill. Read `roughdraft skill path` to find the packaged directory, or use [the published skill](skill/roughdraft/SKILL.md). Install it with `roughdraft skill install <supported-skill-root>/roughdraft`; Pi also discovers it from the pi-roughdraft package. Follow [setup](setup.md) for installation. Do not append this prompt to global agent instruction files.
